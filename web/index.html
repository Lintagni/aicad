Troubleshoot the connection
CHECK IN ORDER
1 · Is AutoCAD running?
The assistant attaches to an open AutoCAD; it does not draw on its own.
2 · Is a drawing open?
Commands cannot run against the Start tab. Open or create any drawing.
—
3 · Has the engine loaded?
It is demand-loaded, so a fresh AutoCAD picks it up on the first AICAD command.
4 · Is AutoCAD waiting for input?
A half-finished command blocks everything. Click in its window and press Esc.
5 · Still stuck?
Reinstall the engine into AutoCAD, then restart AutoCAD so it reloads.
